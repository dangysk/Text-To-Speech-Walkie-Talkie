# Text-To-Speech Walkie Talkies
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0.

## How to use
*Create a tool with a 'Transmitter' tag and a 'Frequency' number attribute.
*Tag any part in workspace as a 'Broadcaster' and give it a 'Frequency' attribute matching to the transmitter you want to give the text-to-speech feature for

Please download the .rbxl file in the following post if you wish to have a better look:

## Features
*Transmitter tools to broadcast ingame chats over broadcasters
*Walkie-talkie/radio voice & sound effects
*Auto-localisation (If players language is set to German, French, Mandarin, etc. it will translate voices to that language.)
*Automatic Voice Gender Assigner (Automatically assigns female voice if transmitter's character looks feminine.)
*Highly configurable

## Configuration
*You may change voice effects in 'AudioEffects.luau'
*You may enable different accents in 'AvailableVoices.luau'
*You may force there to only be males voices in 'AvailableVoices.luau'
*Can disable Auto-Localisation in 'BroadcasterObject\init.luau'.
*Able to enable foreign accents for English in 'AvailableVoices.luau' when Auto Localisation is disabled
*Able to disable Automatic Voice Gender Assigner in 'AvailableVoices.luau' by only allowing male voices

## Getting Started if using Rojo
To build the place from scratch, use:

```bash
rojo build -o "RobloxProjectTemplate.rbxlx"
```

Next, open `RobloxProjectTemplate.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
Otherwise, just copy and paste scripts from the .rbxl file (attached in the link mentioned under 'How To Use' header)
